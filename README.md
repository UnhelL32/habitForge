⚔️ QuestForge —Habit RPG

QuestForge transforms daily habit tracking into an RPG progression system. Complete routines, extend streaks, accumulate experience points, and level up your knight.

⚡ Key Features

 * Gamified Habits: Earn custom XP and gold on quest completion. Automatic leveling mechanics dynamically scale your XP bar.
 * Knight Customization: Name your character and upload custom avatar photos with automated client-side image compression.
 * Milestone Loot Vault: Unlock gear, pets, and artifacts across rarity tiers (Common to Mythic) at streak milestones (3, 7, 15, 21, 30, and 40 days).
 * Audio Feedback: Synthesizes custom 8-bit sound effects for task completions and level-ups via the browser's Web Audio API.
 * Zero Dependencies / Single File: Packaged to run out-of-the-box in modern browsers via CDNs with localStorage persistence.

🚀 Getting Started

No build tooling or package installation required.
 * Save the code as index.html.
 * Open index.html in any web browser.
 * Click New Quest to configure your habits.

🛠️ Tech Stack
 
 * React 18 (Standalone via Babel)
 * Tailwind CSS (CDN)
 * Lucide Icons
 * Web Audio API
 * HTML5 Canvas (Client-side photo optimization)
